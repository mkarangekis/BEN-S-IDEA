# Walk Buddies - Step-by-Step Launch Guide

## Quick Reference
- **Budget:** $10,000
- **Timeline:** 90 days
- **Owners:** Patricia McDonald (40%) + ACG (60%)

---

## Phase 1: Pre-Launch (Days 1-30)

### Week 1: Foundation Setup

**Day 1-2: Legal & Business**
- [ ] Register LLC/business entity
- [ ] Open business bank account
- [ ] Draft partnership agreement (Patricia 40% / ACG 60%)
- [ ] File trademark for "Walk Buddies"

**Day 3-4: App Store Accounts**
- [ ] Create Apple Developer Account ($99/year)
- [ ] Create Google Play Developer Account ($25 one-time)
- [ ] Set up App Store Connect and Google Play Console

**Day 5-7: Brand Assets**
- [ ] Finalize app icon (1024x1024)
- [ ] Create app screenshots (6-8 per platform)
- [ ] Write app store descriptions (short + long)
- [ ] Design feature graphics

### Week 2: Marketing Infrastructure

**Day 8-10: Digital Presence**
- [ ] Register domain (walkbuddies.app or similar)
- [ ] Build landing page with email capture
- [ ] Set up social accounts: Instagram, TikTok, Facebook
- [ ] Create Linktree or link-in-bio

**Day 11-14: Email & Analytics**
- [ ] Set up email marketing (Mailchimp free tier)
- [ ] Create welcome email sequence (3 emails)
- [ ] Install analytics: Mixpanel/Amplitude (free tier)
- [ ] Set up Firebase for push notifications

### Week 3: Content Creation

**Day 15-18: Content Bank**
- [ ] Shoot 10 TikTok/Reel videos (founder story, how-it-works, use cases)
- [ ] Create 20 static social posts
- [ ] Write 5 blog posts for SEO
- [ ] Design referral program graphics

**Day 19-21: Influencer Outreach**
- [ ] Identify 50 micro-influencers (fitness, wellness, local)
- [ ] Draft outreach templates
- [ ] Send first batch of 20 DMs/emails
- [ ] Negotiate 5-10 partnerships ($50-$300 each)

### Week 4: Beta Testing

**Day 22-25: Private Beta**
- [ ] Recruit 50 beta testers (friends, family, early signups)
- [ ] Create TestFlight/Internal Testing groups
- [ ] Set up feedback collection (Typeform or Google Form)
- [ ] Monitor crash reports and fix critical bugs

**Day 26-30: Final Prep**
- [ ] Incorporate beta feedback
- [ ] Submit to App Store review (allow 3-5 days)
- [ ] Submit to Google Play review (allow 1-3 days)
- [ ] Finalize launch day press kit

---

## Phase 2: Launch (Days 31-60)

### Week 5: Soft Launch

**Day 31-33: Go Live**
- [ ] Publish app on both stores
- [ ] Announce to email list
- [ ] Post on all social channels
- [ ] Notify beta testers to leave reviews

**Day 34-37: Initial Push**
- [ ] Run TikTok ad campaign ($500 budget)
- [ ] Activate first 5 influencer posts
- [ ] Post in 10 Facebook groups (local walking, fitness)
- [ ] Submit to ProductHunt

### Week 6: Momentum Building

**Day 38-42: Community Activation**
- [ ] Partner with 3 local gyms/studios for flyer distribution
- [ ] Host virtual "Walk Together" launch event
- [ ] Engage with every comment and DM
- [ ] Reach out to local news/blogs for coverage

**Day 43-45: Referral Push**
- [ ] Launch referral program (give $5, get $5 or premium features)
- [ ] Create shareable invite cards
- [ ] Reward top referrers publicly

### Week 7-8: Optimization

**Day 46-60: Iterate & Scale**
- [ ] A/B test ad creatives
- [ ] Optimize App Store listing based on search data
- [ ] Double down on best-performing channels
- [ ] Fix bugs from user feedback
- [ ] Send re-engagement emails to inactive users

---

## Phase 3: Growth (Days 61-90)

### Week 9-10: Scale What Works

**Day 61-70: Paid Amplification**
- [ ] Increase budget on winning ad sets
- [ ] Launch Instagram Reels ads
- [ ] Test Google App Campaigns
- [ ] Activate 10 more influencers

### Week 11-12: Retention Focus

**Day 71-84: Engagement**
- [ ] Launch weekly walking challenges
- [ ] Add push notification sequences
- [ ] Create user-generated content campaign
- [ ] Build community features (leaderboards, streaks)

### Week 12: Review & Plan

**Day 85-90: Analysis**
- [ ] Compile all metrics into dashboard
- [ ] Calculate CAC, LTV, retention rates
- [ ] Identify top acquisition channels
- [ ] Plan next 90-day budget and strategy
- [ ] Present results to stakeholders

## Launch Day Checklist

### Morning (Launch Day)
- [ ] Verify apps are live on both stores
- [ ] Send email blast to full list
- [ ] Post announcement on all social platforms
- [ ] Text/DM personal network to download + review
- [ ] Submit to ProductHunt (schedule for 12:01 AM PT)

### Afternoon
- [ ] Monitor app store reviews (respond to all)
- [ ] Engage with social comments
- [ ] Check analytics for any issues
- [ ] Activate first influencer posts
- [ ] Post stories/updates throughout day

### Evening
- [ ] Send thank you to supporters
- [ ] Share early wins on social
- [ ] Screenshot milestone moments
- [ ] Plan Day 2 content
- [ ] Celebrate! 🎉

---

## Quick Wins (First 48 Hours)

1. **Get 20 reviews** - Personal network first
2. **Cross 100 downloads** - Email list + social
3. **First viral moment** - TikTok behind-the-scenes
4. **Press mention** - Local blog or newsletter
5. **First organic referral** - Someone you don't know

---

## If Things Go Wrong

| Problem | Solution |
|---------|----------|
| App rejected | Fix issues within 24h, resubmit |
| Low downloads | Increase paid spend, more influencers |
| Bad reviews | Respond publicly, fix issues fast |
| High uninstalls | Survey churned users, improve onboarding |
| Budget running low | Pause paid, focus on organic/referral |
